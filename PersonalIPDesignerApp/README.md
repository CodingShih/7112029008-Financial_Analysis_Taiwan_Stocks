# Personal IP Designer App

This directory contains a minimal Android project skeleton implementing the "個人IP設計師" service. It demonstrates how Kotlin can be used to build an Android app that connects to a language model backend.

The project uses Kotlin as the main language and targets Android API 24+.

## Modules
- `app`: Android application source with basic activities and placeholder code for LLM API calls.

## Build
This project uses Gradle. Import the project into Android Studio and allow it to download the Android SDK components. The app module contains placeholder code for invoking an LLM service via HTTP.
